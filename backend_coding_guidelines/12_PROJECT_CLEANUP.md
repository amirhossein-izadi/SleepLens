# Project Cleanup & LLM Artifact Management

> Guidelines for managing LLM-generated files, cleanup procedures, and maintaining a clean project.

---

## The Problem

LLMs often generate:
- Redundant documentation
- Duplicate scripts
- Unused files
- Inconsistent naming
- Experimental code left behind

---

## Identifying LLM Artifacts

### Common Patterns

```
# Redundant documentation
AI_GATEWAY_DIAGNOSTIC_REPORT.md    # Auto-generated analysis
AI_SERVICE_TEST_RESULTS.md         # Test output
REPORTS_APP_ANALYSIS.md            # LLM analysis
REPORTS_APP_CLEANUP_PLAN.md        # LLM planning
REFACTORING_SUMMARY.md             # LLM summary

# Duplicate scripts
scripts/test_ai_service.py
scripts/test_ai_simple.py
scripts/test_ai_requests.py        # All do similar things

# Unused files
scripts/preview_file_paths.py      # Never used
scripts/add_file_paths.py          # One-time use
```

---

## Cleanup Decision Tree

```
Is the file:
│
├── Used in daily development?
│   └── YES → Keep
│
├── A one-time script (migrations, fixes)?
│   └── YES → Delete after use
│
├── Auto-generated by tools?
│   └── YES → Keep in .gitignore or delete
│
├── LLM-generated documentation?
│   └── Check below
│
└── Duplicate functionality?
    └── Delete duplicates, keep best
```

## Cleanup Checklist

### Run This to Find Issues

```bash
# Find large files
find . -type f -size +1M | head -20

# Find duplicate filenames
find . -type f -name "*.py" | sort | uniq -d

# Find unused scripts (no imports)
for f in scripts/*.py; do
    grep -r "$(basename $f .py)" apps/ lib/ --include="*.py" || echo "UNUSED: $f"
done

# Find markdown files in root
ls -la *.md
```

### Common File Patterns to Review

| Pattern | Action | Reason |
|---------|--------|--------|
| `*_DIAGNOSTIC_REPORT.md`, `*_ANALYSIS.md` | Delete | LLM-generated analysis |
| `*_TEST_RESULTS.md`, `*_OUTPUT.md` | Delete | Test output artifacts |
| `*_CLEANUP_PLAN.md`, `*_SUMMARY.md` | Delete | LLM planning/summaries |
| `REFACTORING_*.md`, `MIGRATION_*.md` | Delete | One-time planning docs |
| `scripts/test_*_simple.py`, `scripts/test_*_v2.py` | Consolidate | Duplicate experiments |
| `scripts/one_off_*.py`, `scripts/fix_*.py` | Delete after use | One-time utilities |
| `progress.txt`, `notes.md` in root | Move to `docs/` or delete | LLM scratchpad files |

## Documentation Standards

### When to Create Documentation

```markdown
# ✅ Create docs for:
- API endpoints (/docs/ or README.md in app)
- Setup instructions (docs/LOCAL_DEVELOPMENT.md)
- Architecture decisions
- External service integrations

# ❌ Don't create for:
- LLM analysis of code
- Test results
- One-time experiments
- Refactoring plans (keep in PR comments)
```

### Documentation Location

```
docs/
├── LOCAL_DEVELOPMENT.md      # Setup guide
├── EXTERNAL_SERVICES.md      # API integrations
├── MONGODB_USAGE_GUIDE.md    # Database docs
├── accounts/                 # App-specific docs
├── reports/
└── ...
```

## Script Management

### Good Scripts

```bash
# ✅ Useful scripts (keep)
scripts/
├── test_ai_service.py        # If actively used
├── verify_unused_services.py # Utility
└── ...

# ❌ One-time scripts (delete after use)
scripts/preview_file_paths.py    # Was for analysis
scripts/add_file_paths.py        # Was for setup
```

### Script Template

```python
#!/usr/bin/env python3
"""
Script description.

Usage:
    python scripts/my_script.py --arg value
"""
import argparse
# ...

if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="...")
    parser.add_argument("--arg", ...)
    args = parser.parse_args()
    main(args)
```

## Regular Cleanup Schedule

### Weekly

```bash
# Check for unused imports
ruff check . --select=F401

# Find dead code
ruff check . --select=F401,F811

# Check for duplicate imports
ruff check . --select=F401
```

### Monthly

```bash
# Review root markdown files
ls -la *.md

# Check for large files
find . -type f -size +5M

# Review scripts directory
ls -la scripts/
```

### Before Release

```bash
# Full cleanup
make format
make lint
make test

# Remove temporary files
rm -rf __pycache__/
rm -rf .pytest_cache/
rm -rf htmlcov/
rm -rf .coverage

# Verify .gitignore
cat .gitignore
```

## Preventing LLM Artifact Accumulation

### In Prompts

```
❌ Don't ask:
"Create a comprehensive markdown file documenting..."

✅ Instead:
"Create minimal docs only if needed, prefer inline comments"
```

### After LLM Session

```bash
# Review what was created
git status

# Check for unnecessary files
git diff --stat

# Clean before commit
make format
make hooks-run
```

## Gitignore Verification

Your project already has good .gitignore. Verify:

```bash
# Should be ignored
.env                    # Secrets
.env.*                  # Environment files
*.log                   # Logs
__pycache__/            # Python cache
.venv/                  # Virtual env
uv.lock                 # UV lock (optional)
media/                  # User uploads
staticfiles/            # Django static
*.sqlite3               # Local DB
.pytest_cache/          # Test cache
.mypy_cache/            # Type check cache
htmlcov/                # Coverage
.coverage               # Coverage data
```

## Recovery: Restoring Accidentally Deleted Files

```bash
# View deleted files
git status --porcelain | grep "^D"

# Restore single file
git checkout HEAD -- path/to/file

# Restore all deleted files
git checkout HEAD -- .

# Restore from specific commit
git checkout <commit-hash> -- path/to/file
```
