# اسلیپ‌لنز (SleepLens) — راهنمای سریع و گام‌به‌گام راه‌اندازی برای هم‌تیمی‌ها

> این راهنما شامل تمامی دستورات لازم برای کلون کردن برنچ، نصب وابستگی‌های فرانت‌اند و بک‌اند، اجرای پایگاه داده و استقرار سامانه روی سیستم شخصی اعضای تیم است.

---

## ⚡ راه‌اندازی سریع در ۲ دقیقه (خودکار)

کافی است این سه دستور را در ترمینال لینوکس یا مک یا WSL ویندوز اجرا کنید:

```bash
# ۱. کلون کردن برنچ پروژه
git clone <آدرس_مخزن> -b morteza
cd SleepLens

# ۲. اجرای اسکریپت راه‌اندازی خودکار (نصب مجازی، پکیج‌های پایتون و npm، ساخت دیتابیس)
./setup.sh

# ۳. اجرای همزمان بک‌اند و فرانت‌اند
cd webapp
./run_all.sh
```

سپس در مرورگر خود این آدرس‌ها را باز کنید:
- **ایستگاه کاری پزشک (فرانت‌اند):** `http://127.0.0.1:3000`
- **هسته API و دیتابیس (بک‌اند):** `http://127.0.0.1:8000`
- **پنل ادمین جنگو:** `http://127.0.0.1:8000/admin/` (نام کاربری: `admin` / رمز عبور: `admin123`)

## 🛠 پیش‌نیازهای سیستمی

قبل از شروع، مطمئن شوید نرم‌افزارهای زیر روی سیستمتان نصب هستند:
۱. **پایتون نسخه ۳.۱۰ به بالا** (نسخه‌های ۳.۱۱ یا ۳.۱۲ پیشنهاد می‌شود):
   ```bash
   python3 --version
   ```
۲. **نودجی‌اس (Node.js) نسخه ۱۸ به بالا همراه با npm**:
   ```bash
   node -v
   npm -v
   ```
۳. **سرور محلی OpenCode (اختیاری جهت هوش مصنوعی زنده و چت)**:
   اگر اوپن‌کد را نصب دارید، در ترمینال جداگانه اجرا کنید:
   ```bash
   opencode serve --port 4096
   ```
   *(نکته: در صورت فعال نبودن OpenCode، سامانه به طور خودکار از الگوهای بالینی آفلاین استفاده می‌کند و هیچ خطایی رخ نمی‌دهد).*

## 📦 مراحل راه‌اندازی دستی (قدم به قدم)

اگر می‌خواهید هر بخش را جداگانه نصب و اجرا کنید:

### گام اول: راه‌اندازی بک‌اند (Django)
```bash
cd webapp

# ۱. ساخت محیط مجازی پایتون
python3 -m venv .venv

# ۲. فعال‌سازی محیط مجازی
source .venv/bin/activate
# در ویندوز (PowerShell):
# .venv\Scripts\activate

# ۳. ارتقای pip و نصب نیازمندی‌ها
pip install --upgrade pip
pip install -r requirements.txt

# ۴. اجرای مایگریشن‌های پایگاه داده
python manage.py migrate

# ۵. بارگذاری کاتالوگ ۲۰ شاخص بالینی استاندارد
python manage.py seed_metrics
```

### گام دوم: راه‌اندازی فرانت‌اند (React + Vite + Tailwind)
```bash
# در یک ترمینال جداگانه:
cd webapp/frontend

# ۱. نصب پکیج‌های جاوااسکریپت
npm install

# ۲. اجرای سرور توسعه فرانت‌اند
npm run dev
```

فرانت‌اند روی آدرس **`http://127.0.0.1:3000`** بالا می‌آید و به طور خودکار به بک‌اند روی پورت ۸۰۰۰ متصل می‌شود.

## 🔬 بارگذاری داده‌های واقعی Sleep-EDF در دیتابیس

برای وارد کردن تمام ۱۹۷ رکورد پلی‌سومنوگرافی (۱۰۰ بیمار واقعی) و هایپنوگرام‌های استاندارد به دیتابیس:

```bash
cd webapp

.venv/bin/python manage.py ingest_sleep_edf
```

این دستور به طور خودکار:
۱. مشخصات دموگرافیک بیماران را از فایل‌های اکسل استخراج می‌کند.
۲. ۱۰۰ بیمار (`Patient`) و ۱۹۷ آزمایش خواب (`SleepStudy`) در دیتابیس می‌سازد.
۳. ۲۳۸,۷۷۳ اپوک ۳۰ ثانیه‌ای با مراحل واقعی خواب (بیداری، N1، N2، N3، REM) را اینزرت می‌کند.
۴. داده‌ها را به صورت تفکیک‌شده برای هر بیمار در پوشه‌ی `data/sleep_edf_by_patient/{mrn}/` قرار می‌دهد (بدون دست زدن به پوشه اصلی دیتاست).

## ❓ رفع اشکالات احتمالی

### ۱. خطای `ENOSPC: System limit for number of file watchers reached` در فرانت‌اند
- **علت:** محدودیت پیش‌فرض واچرهای لینوکس روی درایوهای مونت‌شده.
- **راه حل:** در فایل `vite.config.ts` پولینگ فعال شده است (`usePolling: true`). در صورت مشاهده مجدد در لینوکس اجرا کنید:
  ```bash
  echo fs.inotify.max_user_watches=524288 | sudo tee -a /etc/sysctl.conf && sudo sysctl -p
  ```

### ۲. تداخل پورت (پورت ۸۰۰۰ یا ۳۰۰۰ اشغال است)
- بررسی پردازه اشغال‌کننده پورت:
  ```bash
  lsof -i :8000
  lsof -i :3000
  ```
- تغییر پورت در زمان اجرا:
  ```bash
  python manage.py runserver 8001
  npm run dev -- --port 3001
  ```
