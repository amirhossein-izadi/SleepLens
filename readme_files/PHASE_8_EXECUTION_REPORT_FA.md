# اسلیپ‌لنز (SleepLens) — گزارش اجرای فاز ۸: یکپارچه‌سازی و آزمون سرتاسری پلی‌سومنوگرافی

---

## ۱. خلاصه‌ی اجرایی بالینی

فاز ۸ سامانه‌ی **SleepLens** (**آزمون جامع سرتاسری و یکپارچه‌سازی ثبت‌های پلی‌سومنوگرافی**) با موفقیت **۱۰۰٪ تکمیل و اعتبارسنجی شد**.

چرخه‌ی بالینی کامل نرم‌افزار به صورت گام‌به‌گام با استفاده از یک ثبت پلی‌سومنوگرافی چندکاناله شبیه‌سازی‌شده (شامل ۱۲۰ اپوک ۳۰ ثانیه‌ای، سیگنال‌های EEG Fpz-Cz، EEG Pz-Oz، EOG افقی، EMG چانه و جریان هوای تنفسی) آزمایش شد: از بارگذاری فایل فشرده، شفافیت فایل‌ها، مرحله‌بندی ۵ کلاسه خواب AASM، استخراج متریک‌های ۷ گانه و شاخص SQI، تا نگارش گزارش تشخیصی فارسی توسط OpenCode، تصحیح مرحله خواب توسط پزشک و بازتولید برخط، ثبت تغییر متریک در لاگ بازرسی، تایید و امضای رسمی پزشک، و گفت‌وگوی تعاملی پزشک با دستیار هوشمند.

### نتایج ارزیابی و آزمون
* **اسکریپت اعتبارسنجی سرتاسری**: `webapp/verify_phase8_e2e.py` ➔ **۱۲ بررسی از ۱۲ بررسی موفق (۱۰۰٪)**
* **آزمون‌های جامع Pytest فاز ۸**: `webapp/tests/test_phase8_e2e.py` ➔ **۵ آزمون از ۵ آزمون موفق (۱۰۰٪)**
* **کل آزمون‌های مخزن**: **۲۸ آزمون موفق در تمام ۸ فاز با صفر خطا**

## ۲. دیاگرام معماری جریان بالینی آزموده‌شده

```
[ثبت مشخصات و شرح حال بالینی بیمار]
  • بیمار: سیاوش قمیشی (۵۱ ساله، مذکر، شکایت خواب غیرترمیمی و شک به OSA)
  • شماره پرونده پزشکی: MRN-E2E-PSG-8819
               │
               ▼
[گام ۱: بارگذاری داده‌های چندکاناله پلی‌سومنوگرافی]
  • آرشیو: siavash_psg_e2e.zip (۱۲۰ اپوک ۱۰۰ هرتز، ۵ کانال حسگر)
  • POST /api/v1/studies/upload/ ➔ وضعیت HTTP 201 Created (شناسه آزمایش: 01a0d4cc-...)
               │
               ▼
[گام ۲: اجرای پایپ‌لاین ۴ مرحله‌ای بدون مسدودی (ThreadRunner)]
  • مرحله ۱ (استخراج): باز کردن ۱۲۴ فایل، اعتبارسنجی هش SHA-256 و ثبت StudyFile
  • مرحله ۲ (مرحله‌بندی): طبقه‌بندی ۱۲۰ اپوک به مراحل AASM (بیداری: ۱۵، N1: ۱۰، N2: ۴۵، N3: ۲۵، REM: ۲۵)
  • مرحله ۳ (موتور متریک‌ها): محاسبه ۷ دسته شاخص ➔ شاخص کیفیت خواب (SQI): ۹۹.۰ از ۱۰۰ (عالی)
  • مرحله ۴ (گزارش هوش مصنوعی): ارسال به OpenCode محلی (پورت ۴۰۹۶) ➔ نگارش گزارش فارسی با کدهای تشخیصی ICD-10
               │
               ▼
[گام ۳: ارزیابی تعاملی پزشک در ایستگاه کاری بالینی]
  • کاوشگر فایل‌ها: GET /api/v1/studies/{id}/files/ ➔ شفافیت ۱۰۰٪ فایل‌ها با هش امنیتی
  • بازبینی هایپنوگرام: GET /api/v1/studies/{id}/hypnogram/ ➔ نمایش ۱۲۰ اپوک همراه با امتیاز اطمینان
  • اصلاح مرحله توسط پزشک: PATCH /api/v1/studies/{id}/epochs/0/override/ ➔ تصحیح اپوک ۰ به بیداری با دلیل بالینی
  • محاسبه مجدد برخط: POST /api/v1/studies/{id}/metrics/recalculate/ ➔ به‌روزرسانی آنی کارایی خواب و SQI
  • تغییر دستی متریک: POST /api/v1/studies/{id}/metrics/override/ ➔ تغییر شاخص آپنه به ۱۲.۰ با ثبت لاگ بازرسی
  • امضای نهایی پزشک: POST /api/v1/studies/{id}/report/sign-off/ ➔ ثبت یادداشت پزشک و تاریخ امضا
  • مشاوره بالینی با OpenCode: POST /api/v1/studies/{id}/chat/.../message/ ➔ تحلیل تعاملی کیس با کانتکست بیمار
```

## ۳. جدول نتایج و گواهی‌های اعتبارسنجی

|---|---|---|---|
| **ثبت بیمار** | `POST /api/v1/patients/` | ایجاد بیمار سیاوش قمیشی (MRN-E2E-PSG-8819) | ✅ تایید شد |

| **تغییر دستی متریک** | `POST .../metrics/override/` | تنظیم شاخص آپنه به ۱۲.۰ با لاگ بازرسی کامل | ✅ تایید شد |
| **امضای نهایی پزشک** | `POST .../report/sign-off/` | ثبت یادداشت تخصصی و درج مهر زمانی امضا | ✅ تایید شد |

## ۴. نحوه بازآزمایی و اجرای تست‌ها

```bash
cd webapp

# ۱. اجرای اسکریپت اعتبارسنجی سرتاسری فاز ۸:
.venv/bin/python verify_phase8_e2e.py

# ۲. اجرای آزمون‌های خودکار Pytest فاز ۸:
.venv/bin/pytest tests/test_phase8_e2e.py

# ۳. اجرای کل ۲۸ آزمون سیستم (تمامی فازهای ۱ تا ۸):
.venv/bin/pytest tests/
```
